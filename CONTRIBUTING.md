# Contributing

TuneItAll is proprietary software. A public repository does not grant a right
to copy, redistribute, or reuse its code or artwork. Contributions require
review and written acceptance by the copyright holder.

Before opening a pull request:

1. Keep the change focused and preserve offline-only behavior.
2. Do not add ads, analytics, tracking, accounts, or network permissions.
3. Run `./tools/build.ps1 -AllowUnsigned` with JDK 17 and Android SDK 36.
4. Exercise changed audio/UI behavior on Android 8.0+.
5. Update privacy, store, screenshot, and third-party notices when applicable.

Do not commit signing files, passwords, API keys, local SDK paths, recordings,
or user data. By submitting a contribution, you confirm that you have the right
to provide it and understand that acceptance is not guaranteed.
